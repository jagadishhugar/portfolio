# Jagadish Hugar — Data Science & ML Portfolio

Personal portfolio website showcasing data analytics, relational database design, and machine learning work, built with semantic HTML, custom CSS variables, and vanilla JavaScript.

## Highlights
- **Responsive Layout:** Alternating odd/even section surfaces with a plum and lavender color system (`#231942`, `#5E548E`, `#9F86C0`, `#BE95C4`, `#E0B1CB`).
- **Interactive Navigation:** Smooth section scrolling, mobile menu drawer with keyboard/outside-click dismissal, and an `IntersectionObserver` scroll-spy indicator.
- **Featured Work:** Highlights projects across Power BI sales analytics, SQL Server relational database design, and neural networks.
- **Contact & Resume:** Includes a resume viewer link, direct social/email links, and a contact form wired to a Google Form endpoint.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (`Inter`) & Font Awesome
- GitHub Pages (static hosting)
